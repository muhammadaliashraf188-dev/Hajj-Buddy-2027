# Hajj Buddy 2027 — Professional PWA
Mobile-first Hajj companion with Home, Dashboard, Tools, Hajj Guide, Duas, Qur'an interface, Checklist, Maps, Qibla, Prayer placeholder, Currency, Travel, Dates, Health, Emergency, Language and Settings.

## Run
Serve the folder over HTTPS or localhost. GitHub Pages works for the PWA shell and installation.

## Notes
- Checklist, settings, language, dark mode and bookmarks persist with localStorage.
- Service worker caches the core app shell.
- Qibla/geolocation request real browser permissions and provide fallbacks.
- Quran text is intentionally not fabricated; connect a verified/licensed dataset.
- Prayer times and live maps are integration points rather than invented data.
- 2027 dates shown in the UI are preliminary/tentative and must be confirmed by official authorities.
